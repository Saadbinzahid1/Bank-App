# 🏦 Bankist App

**Bankist** is a minimal banking web application built with modern JavaScript. It simulates real banking operations like logging in, transferring money, requesting loans, closing accounts, sorting transactions, and auto-logging out after inactivity.

This project focuses on practicing **arrays, DOM manipulation, dates & internationalization, timers, and asynchronous-style logic** in JavaScript.

---

## 🚀 Features

- Secure login system
- Display account balance and transaction history
- Transfer money between users
- Request loans
- Close existing accounts
- Sort movements
- Auto logout timer for security
- Localized date and currency formatting

---

## 🛠️ Tech Stack
